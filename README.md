# حفظ تدبری قرآن

اپلیکیشنی برای حفظ قرآن که واحد حفظ در آن **سیاق** است: هر مجموعه آیه با اتصال مفهومی، اول فهمیده، بعد شنیده، بعد حفظ و با مرور فاصله‌دار تثبیت می‌شود. تقسیم‌بندی هدف، روش «تدبر در قرآن کریم» استاد علی صبوحی طسوجی است.

**نسخه وب:** https://kmazraee.github.io/tadabbor-hefz/

## محتوای این مخزن

| مسیر | توضیح |
| --- | --- |
| [`docs/PRD.md`](docs/PRD.md) | سند نیازمندی‌های محصول |
| [`prototype/index.html`](prototype/index.html) | نسخه وب برنامه (کل قرآن، مصحف صفحه‌ای عثمان طه) |
| `data/meta.json` | ۱۱۴ سوره، تقسیم سیاق/بخش و فهرست صفحه هر آیه |
| `data/pages/` | ۶۰۴ صفحه مصحف مدینه (هر صفحه یک فایل، بارگیری هنگام نیاز) |
| `data/rukus.json` | شروع رکوع‌ها؛ بخش‌بندی موقت سوره‌هایی که هنوز داده سیاق ندارند |
| `android/` | پروژه اندروید (برنامه آفلاین) |
| `scripts/build_quran.py` | ساخت داده کل قرآن با بررسی خودکار (۶۲۳۶ آیه، پیوستگی بازه‌ها) |
| `scripts/build_web.py` | ساخت نسخه وب و نسخه داخل برنامه از روی قالب |
| `scripts/prototype_src.html` | قالب برنامه |

## امکانات نسخه ۰.۲

- چرخه پنج‌مرحله‌ای تدبرمحور: تدبر (خواندن، کشف گام‌ها، پرسش‌ها) ← شنیدن ← حفظ گام‌به‌گام ← اتصال با نقشه معنا ← ثبت و مرور
- مصحف صفحه‌ای مدینه به خط عثمان طه برای کل قرآن، با نوار وضعیت سیاق کنار سطرها
- مسیر یادگیری تدبر بر اساس سطح‌های ۱ تا ۶ دوره استاد صبوحی، با درس‌های سایت و نمایش پیشرفت
- فیلم و صوت درس‌های هر سوره از alisaboohi.com
- قاری‌ها: شاطری، پرهیزگار، محمد ایوب
- تنظیمات: پوسته (خودکار، روشن، تیره، کاغذی)، رنگ اصلی، اندازه متن، قلم مصحف، فاصله سطرها، قاری، تکرار
- راهنمای داخل برنامه و معرفی شروع
- پشتیبان‌گیری در گوگل‌درایو (از طریق اشتراک‌گذاری) و بازیابی از فایل

## دانلود برنامه اندروید

آخرین فایل APK در بخش [Releases](https://github.com/kmazraee/tadabbor-hefz/releases) است. نسخه جدید فقط وقتی ساخته می‌شود که یک برچسب نسخه (مثل `v0.2.0`) به مخزن فرستاده شود.

## ساخت دوباره نمونه اولیه

```bash
npm pack quran-json@3.1.2 quran-qcf4@1.1.0
mkdir qj qcf && tar -xzf quran-json-3.1.2.tgz -C qj && tar -xzf quran-qcf4-1.1.0.tgz -C qcf
python3 scripts/build_quran.py qj/package/dist/chapters qcf/package data/rukus.json
python3 scripts/build_web.py
```

اسکریپت ساخت داده اگر آیه‌ای در صفحه‌ها پیدا نشود، بازه‌ها همپوشانی داشته باشند یا تعداد آیات به ۶۲۳۶ نرسد، با خطا متوقف می‌شود.
