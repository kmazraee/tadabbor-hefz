# دستیار هوش مصنوعی بدون سرور (Cloudflare Worker رایگان)

برنامه سرور ندارد، اما کلید API مدل نباید داخل برنامه یا سایت باشد؛ هر کسی می‌تواند آن را از فایل برنامه دربیاورد. برای همین یک «واسط» کوچک رایگان روی Cloudflare ساخته می‌شود: برنامه سؤال را به آن می‌فرستد، واسط با کلیدی که فقط خودش دارد از مدل جواب می‌گیرد و برمی‌گرداند.

هزینه: صفر. Cloudflare Workers روزی ۱۰۰ هزار درخواست رایگان دارد و Gemini نسخه رایگان دارد. چون برای Gemini کارت بانکی ثبت نمی‌کنید، اگر کسی سوءاستفاده کند فقط سهمیه رایگان آن روز تمام می‌شود و پولی از شما کم نمی‌شود.

## ۱. کلید رایگان Gemini

به https://aistudio.google.com/apikey بروید، با حساب گوگل وارد شوید و «Create API key» را بزنید. کلید را جایی امن نگه دارید (در گیت‌هاب نگذارید).

## ۲. ساخت Worker (حدود ۵ دقیقه، از مرورگر)

1. در https://dash.cloudflare.com/sign-up حساب رایگان بسازید (فقط ایمیل).
2. منوی **Workers & Pages** ← **Create** ← **Create Worker** (یا «Start with Hello World»). نامش را `hefz-ai` بگذارید و **Deploy** بزنید.
3. **Edit code** را بزنید، همه کد را پاک کنید، محتوای فایل `deploy/cloudflare/ai-worker.js` همین مخزن را جایش بچسبانید و **Deploy** بزنید.
4. در صفحه Worker: **Settings** ← **Variables and Secrets** ← **Add**: نوع **Secret**، نام `AI_API_KEY`، مقدار کلید Gemini. ذخیره کنید.
5. آدرس Worker را بردارید (چیزی مثل `https://hefz-ai.نام-شما.workers.dev`) و برای Claude بفرستید، یا در فایل `deploy/cloudflare/AI_API` همین مخزن بنویسید. برنامه و سایت با این آدرس دوباره ساخته می‌شوند و دستیار روشن می‌شود.

اختیاری:
- **سرویس دوم** وقتی Gemini جواب نداد (سهمیه یا قطعی): از https://console.groq.com/keys کلید رایگان Groq بگیرید و Secret با نام `AI_FALLBACK_API_KEY` اضافه کنید.
- **محدودیت هر دستگاه** (۱۰ پرسش در دقیقه): با `npx wrangler deploy` در همین پوشه، فایل `wrangler.toml` آن را خودکار تنظیم می‌کند. از داشبورد هم بدون آن کار می‌کند.
- **فقط سایت خودتان:** متغیر `ALLOWED_ORIGINS` با مقدار آدرس سایت (مثلاً `https://ganjineh-tadabbor.ir`)؛ برنامه اندروید همیشه مجاز است.

## نکته‌های ایران

- **تحریم گوگل:** گوگل درخواست از IP ایران را رد می‌کند، اما اینجا درخواست را Cloudflare از مرکز داده‌ای بیرون ایران می‌فرستد، پس کاربر ایرانی مشکلی ندارد.
- **فیلترینگ:** دامنه‌های `workers.dev` گاهی در ایران فیلتر می‌شوند. اگر کاربران بدون فیلترشکن به دستیار نرسیدند، Worker را به یک زیردامنه از دامنه خودتان وصل کنید (Worker ← Settings ← Domains & Routes ← Custom domain، مثلاً `ai.ganjineh-tadabbor.ir`). این کار لازم دارد DNS دامنه روی Cloudflare باشد (رایگان).
- **ثبت‌نام:** ساخت حساب Cloudflare و Google AI Studio ممکن است از ایران فیلترشکن بخواهد؛ فقط یک بار لازم است.
- اگر سرویس جواب ندهد، کادر بالای صفحه همچنان خلاصه ساده روزانه (بدون هوش مصنوعی) را نشان می‌دهد.

## عیب‌یابی

Worker ← **Logs** (یا Observability): خطاهای سرویس مدل با پیشوند `hefz-ai` دیده می‌شود.
