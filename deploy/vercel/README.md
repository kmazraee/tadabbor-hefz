# دستیار هوشمند روی Vercel (جایگزین Cloudflare)

1. در vercel.com با حساب گیت‌هاب وارد شوید، Add New → Project و مخزن `tadabbor-hefz` را انتخاب کنید.
2. در Root Directory مقدار `deploy/vercel` را بگذارید. Framework را Other بگذارید.
3. در Environment Variables مقدار `AI_API_KEY` را با کلید جمنای اضافه کنید و Deploy بزنید.
4. آدرس کار این است: `https://<نام-پروژه>.vercel.app/api/ai` (باز کردن آن در مرورگر باید `POST only` نشان دهد).
